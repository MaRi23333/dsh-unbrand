# Security and privacy

Unbrand changes a small part of the request handed to a model adapter. It is not an anonymity service: a provider can still see connection metadata, and messages, tools or application data can identify the host.

For a possible security issue, use **Security → Report a vulnerability** on GitHub if the repository offers it. Otherwise ask for a private contact channel in an issue without posting sensitive details. Do not attach credentials, conversation histories, complete configuration files, Desktop archives, or unredacted request bodies. A synthetic example, the plugin and Desktop versions, and what was changed or preserved are usually enough to start.

For ordinary compatibility or interface problems, use the bug report form.
