# 隐标使用说明

## 兼容与安装

**隐标 0.1.4 仅支持 DSH Desktop 0.2.2-rc.1。** 插件用到了这个版本的内部接口；其他 Desktop 版本和独立 Web 部署尚不支持。

1. 在 DSH 桌面版打开「插件 → 添加插件」，输入 `dsh-unbrand@0.1.4`。也可以从 [GitHub Release](https://github.com/MaRi23333/dsh-unbrand/releases/tag/v0.1.4) 下载 `dsh-unbrand-0.1.4.tgz`，不解压，在同一处输入文件的完整路径。
2. 安装后启用插件；若提示重启，从应用菜单完全退出，再打开 DSH。
3. 打开「设置 → 隐标」，勾选一个模型并保存。从下一次请求起生效。

从源码运行需要 Node.js 22.19.0 或更高版本。在源码目录执行 `npm ci --ignore-scripts`，再用 Desktop 随附的命令执行 `dsh plugin --profile desktop add .`；保留这个目录。

## 使用

默认模型列表为空，**只启用插件不会改写任何请求**。

在 **设置 → 隐标** 按模型名称、ID 或供应商搜索，勾选需要处理的模型，再点 **保存**。从目录选择只匹配该供应商的这条路由；同名模型可以分别选择。保存后从下一次模型请求生效，无需新建会话。

目录中没有的模型可展开「找不到模型？手动添加」，填写请求实际使用的 ID：

| 规则示例 | 匹配范围 |
| --- | --- |
| `vendor/model-a` | 所有供应商上，模型 ID 恰好为 `vendor/model-a` 的请求 |
| `gateway::vendor/model-a` | 供应商 ID 为 `gateway`，且模型 ID 为 `vendor/model-a` 的请求 |

规则区分大小写，精确匹配，不支持通配符。模型暂时不在目录中时，已保存规则仍保留。关闭过滤或移除全部规则后保存，后续请求恢复原样。

## 用前须知

- 改写宿主固定身份说明和指定的运行上下文定位行；沙箱说明只去掉产品名，权限模式、允许写入的路径和审批要求照原文保留。全局 `AGENTS.md` 在指令开头的来源标题显示为用户全局规则，正文和项目规则标题保持原样。无法确认来源或格式时保留原文。
- 只改变交给模型适配器的副本，不回写历史。用户与助手消息、工具定义和结果、技能、其他插件自行提供的 `system` 或消息不做全局替换。自行直连模型服务的插件不经过此入口。
- 不修改请求头、供应商路由、权限、推理档位或缓存标识；相同有效输入的改写保持稳定。启用或修改规则会改变匹配请求的内容，供应商缓存命中率不作保证。
- 隐标只处理上面列出的宿主文字。对话、工具结果和其他插件仍可能提到 DSH，模型也可能从这些内容判断你在用什么软件。
